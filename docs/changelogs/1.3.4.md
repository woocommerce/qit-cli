### QIT CLI 1.3.4 Release Notes

GitHub's `ubuntu-latest` runners are moving to Ubuntu 26.04, where Playwright before 1.61 cannot install its browsers. This release makes that failure visible and names the fix.

#### Improvements

- A failed Playwright browser install is reported as a warning with the last 20 lines of Playwright's output, or all of it with `-v`. Until now it was only shown with `-v`, so the run went on and every spec failed with an unrelated-looking `Executable doesn't exist`. The run still continues, since API-only test packages need no browser.
- When the install fails because Playwright does not support Ubuntu 26.04, the warning says how to fix it: upgrade the test package's Playwright (`@playwright/test` or `playwright`) to 1.61 or later, or use Ubuntu 24.04.
- Cached test packages get the browser check too, so a cleared browser cache or an earlier failed install is fixed or reported instead of skipped. The check runs once per package in each command.

#### Bug Fixes

- `Playwright browsers already installed` is printed only when it has been confirmed. A check that failed or listed no browsers used to print it as well; it now goes on to the install.
